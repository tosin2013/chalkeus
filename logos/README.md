# Chalkeus logos

The mascot: a bronze robot smith forging `{ }` on an anvil. Chalkeus is Greek for bronzesmith,
and `forge` is the command. Generated with Gemini (`chalkeus-source.jpeg`), then cropped and
exported.

| File | Use |
|---|---|
| `chalkeus-logo.png` | Mascot and wordmark, transparent background (light or dark pages) |
| `chalkeus-logo-dark.png` | Mascot and wordmark on the original charcoal background |
| `chalkeus-mascot.png` | Mascot only, 1024×1024, transparent |
| `chalkeus-avatar.png` | Mascot only, 1024×1024, on charcoal: a GitHub or social avatar |
| `chalkeus-512.png` … `chalkeus-64.png` | Mascot icons: 512, 256, 192, 180 (Apple touch), 128, 64 |
| `chalkeus-48.png`, `chalkeus-32.png`, `chalkeus-16.png` | Head only, so it stays readable when tiny |
| `favicon.ico` | Head only: 16, 32 and 48 px |
| `chalkeus-social.png` | 1280×640, GitHub's social preview (Settings → General → Social preview) |
| `chalkeus-source.jpeg` | The original image |

Colours: charcoal `#25282D` background, bronze body, teal eyes, ember-orange `{ }`.
