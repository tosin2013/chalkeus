# Chalkeus logos

A rocket lifting off from a cloud between two server racks: work leaves your infrastructure as a
reviewed change. Generated with Gemini (`chalkeus-source.png`), then cropped and exported.

| File | Use |
|---|---|
| `chalkeus-logo.png` | Main logo, 1024×1024, transparent background, for light backgrounds |
| `chalkeus-logo-dark.png` | The same with light-grey cloud and racks, for dark backgrounds |
| `chalkeus-logo-white.png` | 1024×1024 on white, where transparency isn't supported |
| `chalkeus-512.png` … `chalkeus-16.png` | Square icons: 512, 256, 192, 180 (Apple touch), 128, 64, 48, 32, 16 |
| `favicon.ico` | 16, 32 and 48 px |
| `chalkeus-social.png` | 1280×640, GitHub's social preview (Settings → General → Social preview) |
| `chalkeus-source.png` | The original image |

Colours: red `#E50101`, grey `#3D444A` (light grey `#E6E8EB` on dark backgrounds).
